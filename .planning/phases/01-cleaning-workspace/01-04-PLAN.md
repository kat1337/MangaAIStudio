<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mouse coordinates -> mask ops | mapToScene-transformed pointer positions drive QPainter draws; out-of-bounds/malformed coords could corrupt the mask |
| brush size input -> QPainter pen width | slider/spinbox values cross into QPen width; oversized widths blow up memory on large pages |
| QImage.bits() -> numpy (core/mask_editor) | buffer pointer crosses into numpy; lifetime hazard if not .copy()-detached |

## STRIDE Threat Register (ASVS L1, block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-09 | Tampering (input validation — brush size) | ToolsPanel.brush_slider/spinbox / EditorCanvas.set_brush_size / core.clamp_brush_size | medium | mitigate | Brush size is clamped to [1,300] via `clamp_brush_size` on EVERY entry to the paint path (the QSpinBox/QSlider also enforce setMinimum(1)/setMaximum(300), and clamp_brush_size is the defense-in-depth guard before QPen width). No unbounded integer reaches QPainter pen width. (RESEARCH §Security Domain V5 input validation.) |
| T-01-10 | Denial of Service (QGraphicsView perf on large pages) | EditorCanvas mouseMoveEvent / update_mask_display | medium | mitigate | Mask painting mutates the existing `self._mask` QImage in place and calls `update_mask_display()` (QPixmap.fromImage + setPixmap); NO new QImage is allocated per mouse-move. SmoothPixmapTransform is already off at zoom>1x (plan 02). This is RESEARCH Pitfall 4. |
| T-01-11 | Tampering (QImage buffer lifetime — use-after-free) | core/mask_editor.mask_to_numpy_binary / numpy_binary_to_mask_qimage | high | mitigate | Both conversions enforce `.copy()` detaching: mask_to_numpy_binary returns `alpha.copy()` (owns its data — verified by test_numpy_extract_copies_buffer OWNDATA assert); numpy_binary_to_mask_qimage returns `qimg.copy()` before the numpy buffer GCs. This is RESEARCH Pitfall 2 and PATTERNS.md §Shared Pattern 5 — MangaCleaner_GPU main_window.py:265-267 is the buggy reference we explicitly do NOT copy. |
| T-01-12 | Tampering (out-of-canvas coordinates) | EditorCanvas mousePress/Move/Release | low | accept | mapToScene coordinates outside the image rect are clipped by QPainter's own scissoring to the QImage bounds; a drag starting outside the mask simply paints nothing. No separate bounds check needed — QPainter handles it. |
</threat_model>

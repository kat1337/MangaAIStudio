<objective>
Persist the per-box style (D-07): the `TextStyle` field joins the `.mas` page-file projection (`project_io.pagebox_to_json`/`json_to_pagebox`) and the `_ocr.json` block dict (`ocr_export.build_page_ocr_json`) — backward-compatible, one dict spelling, V5-coerced on load. The `_ocr.json` change touches the published D-19 contract, so the version policy is a human decision (Task 2 checkpoint) before the writer changes (Task 3).

Purpose: without persistence, styles are session-only. This plan makes them ride the existing save/open/export paths so a styled page round-trips through `.mas` and downstream tools can reproduce the look from `_ocr.json`.

Output: `"style"` field in both projections, `OCR_JSON_VERSION` per the checkpoint decision, and the round-trip/legacy/shape tests. Runs in parallel with plans 07-02/07-03 (Wave 2 — no file overlap; only needs `TextStyle` from 07-01).

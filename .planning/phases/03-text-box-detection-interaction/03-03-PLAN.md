<objective>
Build the TEXT-03 vertical slice's UI core: the `BoxItem` Qt Graphics View component (D-05) with four corner resize handles (D-06), and the `EditorCanvas` box layer + hit-test dispatch (D-07) + create/move/resize/delete/create interactions (D-08/D-12/D-13). After this plan, a user can manually add a box (Alt+drag), select/move/resize/delete it — the full TEXT-03 correction workflow minus detection (which is plan 03-04). The box layer is toggleable (Shift+M) and hidden = not interactable (Pitfall 5).

Purpose: This is the heart of Phase 3. Every box on the canvas (detected from plan 03-04 or user-created here) is a `BoxItem`. The hit-test dispatch slots into the existing `mousePressEvent` BEFORE the mask-tool branch so boxes are always interactive when the layer is visible (D-07 — no 6th tool). The corner handles + amber create-preview + green/amber origin colours are the UI-SPEC §12 contract made concrete.

Output: One new component file, one extended canvas, one GUI test file. Plan 03-04 wires detection output into `set_boxes`; plan 03-05 wires persistence + the undo UI. This plan delivers the standalone box-interaction loop end-to-end.
</objective>

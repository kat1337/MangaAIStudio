Close UAT test 3 addendum (MAJOR, UNDIAGNOSED): after inpainting, the brush
mask comes back on the 2nd Ctrl+Z and no further Ctrl+Z removes it. This is a
Phase 1 FLOW-02 regression surfaced during Phase 3 UAT (the unified timeline
made it reachable in a way Phase 1's split surface masked).

The UAT flags this as `diagnosed: false` and lists the documented SUSPECT (the
pre-existing mask-side one-behind behaviour, established during CR-01
scrutiny: the mask side pushes AFTER-state with NO baseline seed, so the first
stroke of a session is one-behind — undo of the first stroke has nothing
before it to restore to, and the after-state convention means repeated undo can
re-push or stall). The orchestrator note in 03-REVIEW.md confirms: "The
pre-existing mask side (after-state, no baseline seed) is genuinely one-behind
for the first stroke of a session — Phase 1 debt."

This plan does TWO things:
(1) CONFIRMS the suspect by a live probe (Task 1) before coding — the UAT
explicitly says "diagnosed: false ... Needs targeted reproduction: paint one
stroke, inpaint, undo repeatedly, inspect _mask_undo/_mask_redo lengths at
each step." The probe is the RED gate.
(2) Applies the SAME baseline-seeding discipline plan 07 applies to boxes:
the first mask stroke of a per-page session pushes a clean/empty PRE-stroke
baseline so undo of the first stroke restores to it — mirroring how plan 07
makes detection a non-undoable baseline and edits push against it. This is the
UAT fix_direction verbatim ("the mask side needs the same baseline-seeding
discipline as the proposed boxes fix").

ALSO closes WR-01 (None.copy() crash in pop_mask_undo when canvas mask is null
— 03-REVIEW.md open warning, reproduced during CR-01 scrutiny): guard the
per-type pops against a null current value. The UAT notes Gap 4 "May overlap
with WR-01 (None.copy() crash in on_undo when canvas mask is null)" — fixing
both together is correct because both are mask-stack robustness defects on the
same undo path.

Purpose: Make mask strokes fully undoable (FLOW-02 contract the user trusted
in Phase 1) and remove the latent crash.
Output: Baseline-seeded mask undo + WR-01 null guard + regression tests.

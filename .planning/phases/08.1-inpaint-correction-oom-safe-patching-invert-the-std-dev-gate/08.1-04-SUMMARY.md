### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed test_batch_clean_skips_empty_mask legacy 4x4 mask on 8x8 page shape mismatch**
- **Found during:** Task 1 GREEN verification (1 failure: 0 vs 1 call)
- **Issue:** Legacy test fixture `make_pages` creates 8x8 white pages but `_small_mask` is 4x4; `mask_to_numpy_binary` returns 4x4, `inpaint_patches` validates mask shape == image shape and our fallback zeroed mismatched masks, causing has_inpaint false and skip LaMa (0 calls vs expected 1)
- **Fix:** Embed small mask at origin into page-sized zero mask when shape mismatches, preserving D-03 gate for legacy pages (file `manga_ai_studio/core/batch_runner.py`)
- **Verification:** `pytest tests/test_core/test_batch_runner.py -q` 15 passed
- **Committed in:** 26fbac3 (part of Task 1 feat)

**2. [Rule 3 - Blocking] Fixed test_gui_batch fake signatures for new max_inpaint_size threading**
- **Found during:** Task 2 full suite (16 failures, 5 batch with TypeError multiple values for progress_callback)
- **Issue:** `_dispatch_batch` now threads `masker_conf` + `max_size` (6 positional) but fakes had old 4-pos signature `pages, inp_model_path, inp_backend, cleaned_dir, progress_callback`, so 5th positional (masker_conf) was assigned to progress_callback and kwarg duplicate raised TypeError, causing batch to fail and canvas not refresh (mean 255 vs 123)
- **Fix:** Updated all 4 `_fake_batch_clean` fakes to `pages, inp_model_path, inp_backend, cleaned_dir, masker_conf=None, max_inpaint_size=(2048,2048), progress_callback=None, abort_flag=None` and `_fake_batch_detect_and_clean` to include `max_inpaint_size` (file `tests/test_gui_batch.py`)
- **Verification:** `pytest tests/test_gui_batch.py::test_cancel_batch_updates_status_bar -xvs` PASSED, `pytest tests/test_gui_batch.py -q` 22 passed after fix
- **Committed in:** 6b1f17c (part of Task 2)

**3. [Rule 1 - Bug] Fixed detection_boxes and gap_closure gate inversion for uniform pages**
- **Found during:** Task 2 full suite (13 failures: mode_on composite, move refit, threshold live, mas save, inpaint copy, gap_closure recompose/rotate)
- **Issue:** Uniform white pages (200) produce low std (5) -> after 08.1 D-01 inversion they are `will_fill` (fill plane) not `will_inpaint` (auto), so `auto` is empty and tests expecting `auto` has content or `will_inpaint` state failed. Example: `test_mode_on_composite_contains_only_in_box_content` expected auto[10:20,10:20].any() but auto was empty for uniform; `test_move_commit_refits_box_and_border` expected uniform -> will_inpaint then noisy -> gate_skipped, but inverted is will_fill -> will_inpaint
- **Fix:** 
  - `test_mode_on_composite_contains_only_in_box_content`: use noisy page (rng) so the box is high-std -> will_inpaint -> auto has content, and include `will_fill` in solid check (file `tests/test_gui_detection_boxes.py`)
  - `test_move_commit...`: flip to uniform `will_fill` solid and noisy `will_inpaint` solid (file `tests/test_gui_detection_boxes.py`)
  - `test_threshold_live...`: flip to high-std will_inpaint at default 15 solid in auto, will_fill at 100 solid but auto empty (check fill plane), will_inpaint at 0 solid in auto (file `tests/test_gui_detection_boxes.py`)
  - `test_mas_save...`: use noisy page so single box is will_inpaint -> auto has content (file `tests/test_gui_detection_boxes.py`)
  - `test_inpaint_completion...`: update to expect `1 filled · 1 inpainted` and `1 inpainted` with noisy page for will_inpaint (file `tests/test_gui_detection_boxes.py`)
  - `gap_closure` 3 tests: make pages noisy and adjust threshold 50->5 to keep high-std as will_inpaint (files `tests/test_gui_gap_closure.py`, `tests/test_gui_batch.py` noisy pages)
- **Verification:** `pytest tests/test_gui_detection_boxes.py -q` 32 passed, `pytest tests/test_gui_gap_closure.py -k "recompose|threshold_tweak|rotate" -v` 3 passed, full suite `pytest -q` 990 passed
- **Committed in:** 6b1f17c (part of Task 2)

<objective>
Close UAT test 1 (MAJOR, diagnosed): "Text overlay follows box geometry: overlay
text appears ON the box rect and moves/scales with the box on zoom and drag" —
currently the overlay sits at a FIXED scene location (measured 0.0 intersection
with the box after a move), does not visibly scale (flat 14 scene px font at
fit-to-window zoom ~0.3-0.5 renders 4-7 device px, below the §16 10px floor),
and "just looks white" (the 2 scene-px outline is sub-pixel AA'd away below 100%
zoom: 2710 -> 260 -> 0 dark pixels at 1.0 / 0.5 / 0.25 zoom).

The three verified root causes from .planning/debug/04-01-text-overlay-tracking.md
are fixed here, each as ONE fix + its regression tests (headless pytest-qt only,
no model downloads, no new features):

- **RC-1 (Task 1):** the overlay position is computed ONLY inside
  refresh_text_overlay (box_item.py:477), and no geometry/zoom path calls it.
  _sync_handles (box_item.py:379-397) repositions handles + badge but never the
  overlay; the canvas moves boxes via setRect + _sync_handles on every
  mouseMoveEvent during a drag (canvas.py:1022-1023) and on resize commit
  (1597-1598, 1618-1619). Fix: split a lightweight setPos-only
  _reposition_text_overlay() out of refresh_text_overlay() and call it from
  _sync_handles (a full document rebuild per mousemove would be wasteful).
- **RC-2 (Task 2):** UI-SPEC §16 [10,28] viewport-px font clamp unimplemented
  (flat 14 scene px, box_item.py:104). Fix: overlay font =
  clamp(14*zoom, 10, 28)/zoom scene px, re-applied on zoom change;
  _on_zoom_changed_reposition_handles (canvas.py:1445) currently DISCARDS its
  zoom argument — forward it.
- **RC-3 (Task 2):** the 2px outline pen is scene-units and scales to
  invisibility below 100% (cosmetic pens not honored by the text-layout
  renderer — verified in the debug session). Fix: outline width = 2/zoom
  scene px (constant 2 viewport px, matching the badge/handle viewport-px
  philosophy), applied on the same refresh path as RC-2. This is a DOCUMENTED
  deviation from UI-SPEC §Spacing's literal "does not scale with zoom" line —
  the UAT test-1 legibility truth ("legible over light and dark artwork at
  100-800% zoom") is the acceptance contract; the spec file is amended.

Purpose: make the UAT test-1 truth observable — the overlay is a reliable
per-box display surface (D-09/D-11) that tracks geometry and stays legible at
every zoom, including the default fit-to-window zoom.
Output: the 3 root-cause fixes + 7 regression tests + a documented spec
deviation, with the full GUI suite still green.

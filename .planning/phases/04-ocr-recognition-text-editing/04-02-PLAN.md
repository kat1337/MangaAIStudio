    Define `reading_order(box_centers_xy: list[tuple[float, float]], rtl: bool) -> list[int]`:
    - n = len(box_centers_xy); if n <= 1 return list(range(n))
    - Derive col_tol from the page's own geometry: `col_tol = max(40.0, statistics.median(sorted(abs(xs[i+1]-xs[i]) for i in range(len(xs)-1))) if len(xs) > 1 else 40.0)` where xs = sorted(cx for cx,_ in centers) — but use median GAP, not median width (RESEARCH Pattern 4 line 367 derives from inter-center gaps; the executor confirms against RESEARCH Assumption A2 median-box-width alternative and picks the more robust against real pages — gap-based is the recommended default)

    - Order columns: `sorted(column_ids, reverse=rtl)` — RTL (manga) reverses so the rightmost column comes first; LTR (manhwa) keeps leftmost first
    - Concatenate per-column index lists → the permutation

    - Return the count of boxes that were auto-numbered (next_no - 1)

<objective>
Deliver the "boxes become display objects" upgrade (D-09): each BoxItem gains a persistent translucent text overlay (z=120) + a bubble-number badge (z=140), the new Inspector QDockWidget (D-08) surfaces both text fields + metadata for the selected box, and the Toggle Text Overlay action (T, D-12) is an independent third visibility layer. The inline editor itself lands in Plan 05; this plan ships the persistent display + the secondary edit surface.

Purpose: TEXT-04 ("edit the recognized OCR text inline in a box") and TEXT-05 ("add a manual translation as a second text field per box") both require the text to be visible on the canvas (D-09/D-10/D-11) and editable somewhere (the Inspector here; the inline editor in Plan 05). Per UI-SPEC §16/§17/§18, the overlay uses QTextCharFormat.setTextOutline (single clean API, RESEARCH Pattern 3), the badge uses ItemIgnoresTransformations (constant viewport-px, like Phase 3's handles), and the Inspector is a QDockWidget tabbed with Tools (UI-SPEC §18). Per RESEARCH Pitfall 7, the z-order (overlay 120 / badge 140 / handles 150) is the contract that prevents visual collisions.

Output: BoxItem with text+badge children; InspectorPanel dock; Toggle Text Overlay action; GUI tests for overlay rendering + badge + toggle independence.
</objective>

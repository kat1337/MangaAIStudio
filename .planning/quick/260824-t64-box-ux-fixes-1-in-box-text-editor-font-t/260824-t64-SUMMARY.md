## What Was Built

1. **Editor font** (`inline_editor.py`): `enter()` now computes `pixel = max(14, min(64, round(14 / zoom)))` from `canvas.zoom_factor` and applies it via `QFont.setPixelSize` — the proxy is not `ItemIgnoresTransformations`, so a stylesheet-fixed 14px rendered ~3.5 screen px at 25% zoom. The `font-size` fragment was removed from the stylesheet (one font source of truth). Committed-text rendering (`TypesetOverlayItem`/text_renderer) untouched — WYSIWYG D-01 preserved.
2. **Handle grab zones** (`box_item.py`): `CornerHandle` gained `_hit_zoom` + `set_hit_zoom()` (non-positive guard to 1.0, `prepareGeometryChange()` before storing — stale BSP entries would keep the old rect hittable). `_handle_hit_rect(zoom)` uses `half = max(4.0, 18 / zoom) / 2.0`; `shape()` and `boundingRect()` both use it (coarse/fine pass parity). `BoxItem.apply_overlay_zoom` forwards to all four handles on every canvas `zoom_changed`. The painted handle stays 8x8 (UI-SPEC §12b).
3. **Live size commits** (`inspector_panel.py`): a 150ms single-shot `_size_debounce` QTimer created in `__init__`; `connect_commit_handlers` stores `_cb_style_size` and connects `size_spin.valueChanged -> debounce.start()`. Timeout routes through `_emit_style_size_if_changed(self._cb_style_size)` (WR-01 loaded-value guard + Mixed-sentinel guard intact; programmatic loads silent via blockSignals). Enter/focus-loss path unchanged.

# Quick Task 260826-09m: Fix canvas text clipping for overshooting fonts Summary

Two-pass MEASURED canvas render in `TypesetOverlayItem`: pass 1 paints into an oversized scratch surface exactly as the existing transform math dictates, pass 2 measures the TRUE painted bounding box from the scratch alpha channel and crops to it (+1px margin), deriving placement offsets from that measured box — Mango-style glyph overshoot no longer clips on canvas at any rotation.

## What Was Built

**Production (`box_item.py`):**
- `_measure_margin(font_px)` — S = max(64, ceil(used_font_size_px)), bounded by the upstream 1024px font cap (T-Q09M-01).
- `_measured_bbox(qimg)` — true painted bbox from the scratch alpha via the renderer's shared `_qimage_argb_to_numpy` bridge.
- `_expand_bbox(bbox, w, h)` — grows the crop 1px per side (the no-clip margin contract), clamped.
- Unrotated path (`set_content`): same CR-01 cancel-translate shifted by S into a (w+2S, h+2S) scratch; measure → single retry with doubled S on border contact → expand-crop; `_ink_offset = QPointF(ink.left() - pad + bx - S, ink.top() - pad + by - S + dy)` with dy unchanged. `_render_offset` stays None / `_baked_rotation` reset to 0 as before.
- Rotated path (`_render_rotated`): corner mapping through `_g` UNCHANGED for the analytic box, inflated by S for the scratch; translate `(t0x - left', t0y - top')`; measure/retry/expand via a shared closure; `_render_offset` uses the measured min-corner in the existing `P = min_g - t0` expression. `_baked_rotation` assignment untouched in `set_content`.
- `refresh_position`, `boundingRect`, preview_rotation/clear_preview_rotation, renderer_layout/renderer_paint: all untouched (RC-1 holds).

**Tests (`tests/test_gui_sfx_editing.py`, +5 test functions / 6 cases):**
- Mango 'M' @100px regression (skipif on user-local `Mango.otf`): no alpha>0 pixel on any pixmap border AND height strictly exceeds the analytic ink+pad estimate. RUNS on this machine (not skipped).
- Generic any-font margin guarantee (default family, 24px).
- D-01 placement equivalence parametrized over [0.0, 40.0] deg vs `bake_typeset_page` within calibrated AA envelopes.
- Empty-text cache-clear guard after a rotated render (pixmap/layout_result/_render_offset None, baked rotation 0).

## Deviations from Plan

**1. [Rule 3 - Blocking] `test_gui_boxes.py::test_overlay_align_v_preserves_dy` asserted the legacy exact `_ink_offset` formula**
- **Found during:** Task 1 verify
- **Issue:** The unit test pinned `_ink_offset.y() == ink.top() - pad + dy` exactly; the plan's must-haves explicitly change that formula by the measured-vs-analytic delta (file not in `files_modified`, but Task 1's verify requires this suite green).
- **Fix:** Rewritten to assert `offset(case) - offset(same-mode dy==0 reference) == dy` exactly (the measured glyph-delta is align_v-independent because the scratch mapping cancels origin) — full G-07-5 regression strength preserved.
- **Files modified:** tests/test_gui_boxes.py
- **Commit:** 01bb357

**2. [Rule 1 - Bug] Exact-bbox crop violated the >=1px margin contract**

- **Fix:** `_expand_bbox` grows the crop 1px/side (clamped); offsets derive from the expanded box; composite proven pixel-equivalent by probe.
- **Files modified:** manga_ai_studio/gui/box_item.py

- **Files modified:** tests/test_gui_sfx_editing.py

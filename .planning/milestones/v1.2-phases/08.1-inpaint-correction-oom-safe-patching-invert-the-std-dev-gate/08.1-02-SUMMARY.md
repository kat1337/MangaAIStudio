## Decisions Made

- Fill headlessly via vendored PIL sequence (masker.py 104/138 exact) before LaMa so LaMa halos do not overwrite fill (halo only where inpaint_binary, later patch wins overlap, untouched outside union bbox pixel-exact)
- Worker reads threshold from profile_manager.masker.mask_max_standard_deviation on worker thread (headless-safe, no Qt), max_size as (max,max) tuple clamped 512..8192, one patch live ordering via inpaint_patches
- Fast-path halo fix was required because fake inpaint_fn paints whole image (Naive) whereas real LaMa preserves unmasked pixels; halo limits copy to dilated mask so fill survives on small pages
- Inpaint() gate expanded to allow fill-only pages (no composite mask but boxes_snapshot has fill) — worker's both-empty passthrough still handled
- Progress wrapper maps patch n/total to 50+40*n//total and "Inpainting n of N…" for status bar parity with batch

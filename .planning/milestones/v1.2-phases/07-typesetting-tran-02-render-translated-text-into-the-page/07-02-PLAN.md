<objective>
Lift Phase 3 D-08 single-select to multi-select (D-08/D-09): Shift+click toggle, click-empty clears, Ctrl+A Select All Boxes, grouped move + grouped delete — each pushing ONE BOXES snapshot so one Ctrl+Z reverses the whole group op. This is the mechanism that makes D-06 "per-page styling" real ("Select All Boxes + apply" in plan 07-05) and the bulk-edit foundation the Inspector styling section consumes.

Purpose: multi-select is pure canvas state-machine work — no model or renderer changes. It can run in parallel with the renderer-depth and persistence plans (Wave 2) and must land before the Inspector's common-value styling section (plan 07-05, Wave 3).

Output: multi-select interaction + grouped move/delete in `gui/canvas.py`, the Select All Boxes action in `gui/main_window.py`, the N-selected affordance + primary-only handles in `gui/box_item.py`, and the full multi-select GUI test battery in `tests/test_gui_boxes.py`.
</objective>

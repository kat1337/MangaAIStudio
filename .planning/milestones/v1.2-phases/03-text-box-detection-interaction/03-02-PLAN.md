This plan widens both entry shapes to `(stamp, value)` — a mechanical change to four push/pop methods — and updates the existing guards. Pure Python, headless-testable, no Qt beyond QImage (which is already imported).

Output: HistoryManager with three stacks + unified undo/redo; updated Phase 1 guards; new BOXES + unified-timeline test file. No UI changes (the toolbar/menu/shortcut collapse is plan 03-05).
</objective>
